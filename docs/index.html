🧩 Modules Sora

Tous les modules de MXFia19/module-sora pour Sora, Luna et les apps compatibles : films, séries, anime, manga. La liste se lit directement dans le dépôt, elle est donc toujours à jour.

Ajouter un module : cliquez sur Copier le lien, puis collez-le dans l'app (Sora : Réglages → Modules → Ajouter). Dans ModuleTester, ajoutez directement le dépôt MXFia19/module-sora dans « Dépôts » pour tout récupérer d'un coup.
